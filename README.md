# Inventory Management System

A simple **Inventory Management System developed using Python**.
The project allows users to manage product details, update stock quantities, and generate bills through a menu-driven program.

## Features

* Add and store product details
* View available products
* Update product stock
* Generate bills
* Store inventory data using file handling
* Maintain an activity log
* Menu-driven user interface

## Technologies Used

* **Python**
* Object-Oriented Programming (OOP)
* Classes and Objects
* File Handling
* Lists and Dictionaries
* Functions
* Conditional Statements
* Loops
* Packages

## How It Works

The program provides a menu-driven interface for performing different inventory operations.

Users can manage product information, update stock quantities, and generate bills. Product information is stored in text files, allowing the inventory data to be maintained between program executions.
